# Deutsch (de) glossary

Tone: informal "du"; English CS terms as German players use them (capitalised nouns). No em dashes. Brand and persona names stay as they are (FRAGMIND, FRAGMIND Coach,
Personal Coach, Pro, Basic, Free plan names, Quick, Deep). Map callouts, weapon names and stat
abbreviations (ADR, KAST, HS, K/D, AWP) are never translated.

`apps/web/src/composition/i18n.test.ts` requires every key in every language. AI output rules for
this language live in `packages/coaching/src/languages.ts`.
